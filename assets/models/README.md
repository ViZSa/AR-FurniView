# 3D Models Directory

Place your 3D model files here (.glb or .gltf format).

## Supported Formats

- **.glb** (recommended) - Binary GLTF format
- **.gltf** - Text-based GLTF format with separate texture files

## Sample Models

You can download free 3D furniture models from:
- [Sketchfab](https://sketchfab.com/)
- [Poly Haven](https://polyhaven.com/)
- [TurboSquid](https://www.turbosquid.com/)
- [CGTrader](https://www.cgtrader.com/)

## File Naming Convention

- `sofa.glb`
- `table.glb`
- `chair.glb`
- `bed.glb`

Make sure to update the `modelUrl` in `furniture_provider.dart` with the correct file paths.
