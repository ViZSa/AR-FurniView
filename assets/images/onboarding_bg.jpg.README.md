# Onboarding Background Image

Place your onboarding background image here as `onboarding_bg.jpg`.

For the best result, use an image that shows:
- A beautiful living room with modern furniture
- A blue/gray sofa with cushions
- Pendant lamps
- Light, clean aesthetic

**Recommended specifications:**
- Format: JPG or PNG
- Resolution: 1080x1920 or higher
- Aspect ratio: 9:16 (portrait)

Alternatively, you can use a solid color or gradient background by modifying the `onboarding_screen.dart` file.
