# Images Directory

Place your product images here (JPG, PNG formats).

## Recommended Specifications

- **Format**: PNG or JPG
- **Resolution**: 1024x1024 or higher
- **Aspect Ratio**: 1:1 (square) or 4:3
- **Background**: White or transparent (PNG)

## File Naming Convention

- `sofa1.jpg`
- `table1.jpg`
- `chair1.jpg`
- `bed1.jpg`

Make sure to update the `imageUrl` in `furniture_provider.dart` with the correct file paths.
